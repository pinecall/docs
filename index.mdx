title: "A voice agent is a class"
description: "Its fields are the state of the call, its @tool methods are what the model may do, and the docstring of each one is what the model reads to choose it. It answers by web, WhatsApp and telephone, and it runs on your own machine."
---

```tsx clinica-norte/agent.tsx
export default class ClinicaNorte extends Agent {
  phone = "+34910000000";
  language = "es";

  stage: Stages<"identify" | "choose" | "book"> = "identify";
  patient?: Patient;
  slot?: Slot;

  /** Busca al paciente por nombre y teléfono. Pide los dos antes de llamarla. */
  @tool({ stage: "identify" })
  async findPatient(name: string, phone: string) {
    this.patient = await patients.find(name, phone);
    this.stage = this.patient ? "choose" : "identify";
  }
}
```

## Five minutes

<Steps>
  <Step title="Install both halves">
    ```bash
    pip install pinecall     # pinecall-runtime: the gateway, the worker, migrate, doctor
    ```

| role | default | variable | where the key comes from |

| `llm` | Anthropic, `claude-haiku-4-5-20251001` | `ANTHROPIC_API_KEY` | [console.anthropic.com](https://console.anthropic.com/settings/keys) |
| `stt` | Soniox | `SONIOX_API_KEY` | [console.soniox.com](https://console.soniox.com) |
| `tts` | ElevenLabs, `eleven_flash_v2_5` | `ELEVEN_API_KEY` | [elevenlabs.io](https://elevenlabs.io/app/settings/api-keys) |
| embeddings | the `tei` container | — | nothing to buy — it runs locally |

The first row is the only one you need to start: the text session builds no ears and no voice, so
an `ANTHROPIC_API_KEY` alone carries you to [Spoken calls](/start/from-zero#spoken-calls).
